Nº 06LES MATHS, EN CLAIR

La formule,
terme par terme.

P(C | E) = P(E | C) · P(C) / P(E)
« Bayes est appelée la formule de la probabilité des causes : elle permet de remonter le temps, c'est-à-dire de calculer la probabilité d'une cause sachant celle de sa conséquence. »
C
PRIOR
Ce qu'on sait avant. Le taux de base : ex. 1 personne malade sur 1 000.
E | C
VRAISEMBLANCE
Si la cause est vraie, à quelle fréquence l'effet apparaît-il ?
E
ÉVIDENCE
Fréquence de l'effet, toutes causes confondues. Vrais + faux positifs.
C | E
POSTERIOR
La réponse cherchée. La proba de la cause sachant l'effet observé.

L'algorithme, en 8 lignes.

// Forme « cote » : multiplications stables, ordre indifférent
function bayesUpdate(prior, evidences) {
  let odds = prior / (1 - prior);          // cote initiale
  for (const e of evidences.filter(e => e.on)) {
    odds *= e.pIfCause / e.pIfNotCause;     // ratio de Bayes
  }
  return odds / (1 + odds);                // → probabilité
}

L'exemple chiffré.

Soit une maladie rare touchant 1 personne sur 1 000 (P(C) = 0,001), avec un test fiable à 99 % (P(E|C) = 0,99) et 1 % de faux positifs (P(E|¬C) = 0,01). 

P(test+) = 0,99 × 0,001 + 0,01 × 0,999  =  0,01098
P(malade | test+) = (0,99 × 0,001) / 0,01098  ≈  0,090   →   ~9 %

Surprise : un test très fiable, sur une maladie rare, ne donne que 9 % de probabilité d'être malade. Le prior écrase la vraisemblance.
