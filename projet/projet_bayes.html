Les maths derrière.

  
La formule de Bayes — décortiquée, illustrée, démontrée par l'exemple.


  

    

      P(C|E) =
      
        P(E|C) · P(C) / P(E)
      
    

  


  

    « Bayes est appelée la formule de la probabilité des causes :
    elle permet de remonter le temps, c'est-à-dire de calculer
    la probabilité d'une cause sachant celle de sa conséquence. »
  


  
Les 4 termes — un par un


  

    

      
P(C | E) — POSTERIOR

      

        La probabilité que la cause soit vraie, sachant qu'on a observé l'effet.
        C'est la valeur que tous nos simulateurs calculent et affichent en grand.
      

    

    

      
P(E | C) — VRAISEMBLANCE

      

        Si la cause est vraie, à quelle fréquence l'effet apparaît-il ?
        C'est la fiabilité de chaque indice — réglée par les sliders.
      

    

    

      
P(C) — PRIOR

      

        Ce qu'on savait avant d'observer l'effet. Le taux de base.
        Pour une maladie rare : 1/1000. Pour le spam dans une boîte : ~30 %.
      

    

    

      
P(E) — ÉVIDENCE

      

        À quelle fréquence on observe l'effet, toutes causes confondues.
        Calculé par : P(E|C)·P(C) + P(E|¬C)·P(¬C).

L'algorithme « odds » — code source

  
// Forme « cote » : multiplications stables, ordre indifférent
function bayesUpdate(prior, evidences) {
  let odds = prior / (1 - prior);          // cote initiale
  for (const e of evidences.filter(e => e.on)) {
    odds *= e.pIfCause / e.pIfNotCause;     // ratio de Bayes
  }
  return odds / (1 + odds);                // → probabilité
}


  
Exemple chiffré — le test médical

  

    

      Soit une maladie rare touchant 1 personne sur 1000 (P(C) = 0,001),
      avec un test fiable à 99 % (P(E|C) = 0,99) et 1 % de faux positifs
      (P(E|¬C) = 0,01).
    

    
P(test+) = 0,99 × 0,001 + 0,01 × 0,999  =  0,01098
P(malade | test+) = (0,99 × 0,001) / 0,01098  ≈  0,090   →   ~9 %

    

      Surprise : un test très fiable, sur une maladie rare, ne donne que 9 % de probabilité d'être malade.
      Le prior (taux de base) écrase la vraisemblance.
