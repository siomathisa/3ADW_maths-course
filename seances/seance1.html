Ensemble de Mandelbrot

L'ensemble de Mandelbrot est l'ensemble des nombres complexes c pour lesquels la suite définie par itération ne diverge pas vers l'infini.

zn+1 = zn² + c  ,  z0 = 0

On colorie chaque pixel selon le nombre d'itérations nécessaires avant que |z| dépasse 2. Les points qui ne divergent jamais appartiennent à l'ensemble.

𝕊

Les ensembles

Un ensemble est une collection d'objets distincts. On distingue :

ℕ entiers naturels
ℤ entiers relatifs
ℚ rationnels
ℝ réels
ℂ complexes

Opérations : union ∪, intersection ∩, complément, inclusion ⊂.

ℂ

Nombres complexes

Un nombre complexe s'écrit z = a + bi avec a la partie réelle et b la partie imaginaire, où i² = −1.

Le module est |z| = √(a² + b²).
On peut le représenter dans le plan complexe (plan d'Argand) avec l'axe réel en abscisse et l'axe imaginaire en ordonnée.

z · z̄ = |z|²

Probabilités

La probabilité mesure la vraisemblance d'un événement. Pour un espace équiprobable :

P(A) = card(A) / card(Ω)

Propriétés : 0 ≤ P(A) ≤ 1, P(Ω) = 1, P(∅) = 0.
Complément : P(Ā) = 1 − P(A).
Union : P(A∪B) = P(A) + P(B) − P(A∩B).

→ Exercice : simulation de lancer de pièce pour estimer P(pile).

Vecteurs

Un vecteur est défini par une direction, un sens et une norme. En 2D :

v⃗ = (vx, vy)

Déplacement d'un point A(x, y) par un vecteur v⃗ :

A' = (x + vx, y + vy)

→ Exercice : déplacement interactif d'un point dans un canvas.

Histoire du web

1989 : Tim Berners-Lee invente le World Wide Web au CERN.
1991 : Premier site web public.
1993 : Navigateur Mosaic, démocratisation.
1995 : JavaScript créé par Brendan Eich en 10 jours.
1996 : CSS1 standardisé par le W3C.
2004 : Firefox, début de la modernisation.
2008 : Chrome & V8, performances JS décuplées.
2015 : ES6 / ES2015, JavaScript moderne.
